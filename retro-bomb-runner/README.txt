RETRO BOMB RUNNER — Huong dan choi offline
==========================================

YEU CAU:
  - Windows 10/11
  - Node.js (tai tai: https://nodejs.org — chon LTS)

CACH CHOI:
  1. Giai nen folder nay ra bat ky dau
  2. Kich doi vao file "play.bat"
  3. Trinh duyet tu dong mo game
  4. Nhan Ctrl+C trong cua so den de thoat server

PHIM DIEU KHIEN:
  Nguoi choi 1:  WASD di chuyen, Space dat bom
  Nguoi choi 2:  Mui ten di chuyen, Enter dat bom
  May tinh don:  WASD + Space

CHE DO CHOI:
  - 1 nguoi: Tim loi ra (cuoi ban do)
  - 2 nguoi: Versus (ai chet truoc thua)
